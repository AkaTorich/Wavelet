# Wavelet — плеер музыки и видео

Проигрыватель с собственной библиотекой и базой. Программа обходит выбранные папки, читает теги и обложки,
и потом всё находится одним полем поиска по названию, исполнителю, альбому, жанру, году, папке и своим меткам.
Сделан на Rust и Tauri 2, окно на HTML/CSS/JS без Node. Работает на Windows и Android; код для iPhone общий,
собирается на машине с macOS (см. ниже). Оформление одно — «Киберпанк» из ThemeLibrary.

Готовое в корне: `Wavelet.exe`, `Wavelet_1.0.0_x64-setup.exe` (установщик), `Wavelet.apk`.

## Что умеет и где лежит

| Что | Где |
|---|---|
| База SQLite: папки, записи, свои метки, списки, настройки; поисковый указатель FTS5 обновляется триггерами | `core/src/db.rs` |
| Обход папок в отдельном потоке: новые и изменённые файлы читаются, неизменённые пропускаются (размер + время), пропавшие удаляются | `core/src/scan.rs` (`scan`) |
| Теги MP3/FLAC/OGG/Opus/M4A/WAV (крейт lofty): чтение, запись правки в файл, вшитые обложки, обложки-картинки рядом (cover.jpg, folder.jpg…) | `core/src/tags.rs` |
| Длительность и размер кадра MP4/MOV по коробкам moov (WebM — длительность ставит проигрыватель) | `core/src/video.rs` |
| Субтитры рядом с видео: `имя.vtt`, `имя.srt`, `имя.ru.srt`; SRT → VTT, кодировка UTF-8 или Windows-1251 | `core/src/subs.rs` |
| Поиск: слова по началу, без учёта регистра; уточнения `исполнитель:` `альбом:` `жанр:` `название:` `метка:` `год:1990-1999` `вид:видео` `папка:` (и английские `artist:` …), фразы в кавычках | `core/src/search.rs` (`parse`, `list_media`) |
| Сводки: альбомы, исполнители, жанры, папки, метки, итог библиотеки | `core/src/browse.rs` |
| Счётчик прослушиваний, оценка, место остановки видео, свои метки, правка тегов, настройки | `core/src/library.rs` |
| Списки воспроизведения: создать, переименовать, удалить, добавить, убрать, переставить | `core/src/playlists.rs` |
| Команды окна и состояние (база под замком, обход в потоке, события `scan-progress` / `scan-done`) | `app/src/commands.rs`, `app/src/state.rs` |
| Проигрыватель: очередь, перемешивание, повтор, громкость, счётчик (половина записи или 4 мин), продолжение видео, субтитры, кнопки мультимедиа Windows и шторки телефона (Media Session), память очереди между запусками | `app/ui/js/player.js` |
| Полоса проигрывателя, видео на месте списка, полный экран, «Сейчас играет» на телефоне | `app/ui/js/playerui.js` |
| Длинные списки без тормозов (рисуются только видимые строки), выделение, меню, перетаскивание | `app/ui/js/vlist.js` |
| Виды: музыка, поиск, исполнитель, жанр, папка, метка, недавние, частые, история | `app/ui/js/views/library.js` |
| Альбомы и страница альбома | `app/ui/js/views/albums.js` |
| Видео: сетка кадров, кадры делаются сами и сохраняются | `app/ui/js/views/video.js`, `app/ui/js/thumbs.js` |
| Списки воспроизведения; перетаскивание записей на название списка слева | `app/ui/js/views/playlists.js`, `app/ui/js/main.js` |
| Меню записи, окна: теги файла, метки и оценка, выбор списка | `app/ui/js/menu.js`, `app/ui/js/views/common.js` |
| Настройки: папки, обход, итог, клавиши | `app/ui/js/views/settings.js` |
| Очередь | `app/ui/js/queue.js` |
| Переходы, боковая панель, вкладки телефона, клавиши, «назад» Android | `app/ui/js/main.js` |
| Вид: раскладка, списки, проигрыватель, телефон; тема «Киберпанк» | `app/ui/css/*.css` (`theme.css` — выгрузка из ThemeLibrary) |

Форматы: музыка MP3, FLAC, OGG, Opus, M4A, AAC, WAV; видео MP4 (H.264), M4V, MOV, WebM. MKV и AVI не играются —
встроенный проигрыватель окна их не понимает.

## Где программа хранит данные

`%APPDATA%\top.globthe.wavelet\` — `wavelet.db` (база) и `covers\` (обложки и кадры видео). На Android — в папке приложения.

## Сборка

Rust ставится через rustup, tauri-cli — `cargo install tauri-cli --version "^2" --locked`.

- Проверки: `cargo test --release --workspace` (база, обход настоящих WAV с тегами, поиск, метки, списки, видео, субтитры).
- Windows: `cargo build --release -p wavelet --jobs 2` → `target\release\Wavelet.exe`;
  установщик: в `app` — `cargo tauri build --bundles nsis -- --jobs 2` → `target\release\bundle\nsis\`.
  Готовые exe и установщик копируются в корень.
- Android: `powershell -ExecutionPolicy Bypass -File tools\build-android.ps1` → `Wavelet.apk` в корне.
  Набор Android (JDK 17, SDK, NDK 27.2, Gradle) берётся с внешнего диска `<буква>:\JavaSDK` (`tools\android-env.ps1`
  ищет его сам). Библиотеки Rust собирает Tauri, но его последний шаг (символьная ссылка) без прав администратора падает,
  поэтому скрипт кладёт `.so` в `jniLibs` копированием и зовёт Gradle без его задач Rust; на время работы Gradle папка
  проекта подключается буквой `W:` — Gradle не терпит русских букв в пути.
  Подпись — свой ключ `android-keystore\wavelet.jks`, пароль в `android-keystore\keystore.properties`.
  Своё в проекте Android (`app\gen\android`, после `cargo tauri android init` переносить вручную):
  - `AndroidManifest.xml` — разрешения на музыку, видео, картинки (обложки), уведомления и службу проигрывания;
  - `MainActivity.kt` — спрашивает разрешения; при сворачивании, если играет музыка, снова пускает WebView
    (оболочка Tauri ставит его на паузу вместе со звуком) и запускает службу;
  - `PlaybackService.kt` — служба «Играет в фоне» с уведомлением, сама гаснет после минуты тишины;
  - `app\build.gradle.kts` — подпись своим ключом.
  На Android файлы субтитров (.srt) не видны программе — система показывает ей только музыку, видео и картинки.
- iPhone: только на macOS. `.github/workflows/ios.yml` собирает на GitHub (вручную, вкладка Actions).
  Для установки на телефон нужна учётная запись разработчика Apple (секрет `APPLE_DEVELOPMENT_TEAM`). Не проверялось.

## Инструменты (`tools\`)

- `fix-ico.ps1` — после `cargo tauri icon icon.svg` обязательно: переписывает мелкие размеры в `app\icons\icon.ico`
  несжатыми картинками (с PNG внутри Проводник рисует на ярлыке пустую заглушку).
- `export-theme.ps1` — заново выгрузить тему «Киберпанк» из ThemeLibrary в `app\ui\css\theme.css` (библиотека только читается).
- `run-debug.ps1` + `cdp.ps1` — запуск с отладочным портом WebView2 и проверка окна: выполнить код в окне, снять картинку
  при заданной ширине (`-Width 390 -Height 800`).
- `core\examples\demo.rs` — пробная библиотека (мелодии WAV с тегами): `cargo run --release -p wavelet-core --example demo -- <папка> [обложка.png]`.
